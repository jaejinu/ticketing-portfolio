# 2026-10-16 추가 기능 구현·검증

실제 PG 연동은 제외했다. 사용자 확정 정책은 공연 시작 전·수수료 없음·결제 전체 전액 환불, 할인 기본 비활성화와 주최자의 회차별 할인·하한 설정이다.

## 구현

- 본인 결제의 환불 견적·직접 환불 API와 티켓 상세 확인 UI. 기존 환불 복구·중복 방지 경로 재사용.
- 기본 0%, 최대 30% 할인. 점유 증가에 따라 할인 항 감소, 설정 하한 준수. 판매 전 설정과 감사 사유.
- 결제 검색과 전체 조건의 상태별 판매/환불 집계. 결제 목록과 합계를 같은 DB 스냅샷에서 조회.
- 사용자 잠금 전용 필터, 이메일 검색 페이지, 구매자 UUID 표시.
- 관리자 공연 메타 대리 수정과 변경 사유/행위자 감사 기록.
- 판매 전 공개 취소·DRAFT 삭제·좌석 행 삭제, 수동 매진. 좌석 합계 갱신과 상태 변경 잠금 보강.
- 사용자/IP 수동 차단 및 최대 24시간 임시 매크로 허용. 인증·요청 속도 제한·대기열은 면제하지 않음.
- 환불 알림 DB 큐, 중복 이벤트 흡수, 누락 환불 보충, lease fencing, SMTP/Mock FCM 발송, 최대 10회 재시도, 관리자 실패 재등록.
- `docs/PROJECT_GUIDE.md`에 스택·기술·기능·정책·운영 제한을 통합.

- Java 21, 전체 Gradle 테스트: **282 tests, failures 0, errors 0, skipped 0**.
- Node 24, 프론트 ESLint·TypeScript·production build 통과.
- Playwright: **153 passed** (51개 시나리오 × desktop Chromium / mobile Chromium / mobile WebKit).
- 신규 핵심 검증: 타인 결제 환불/견적 거부, 중복 환불 단일 이벤트, 마감 후 취소 거부, 전체 집계와 페이지 분리, 할인 계산/판매 후 변경 거부, 판매 이력에 따른 삭제/공개 취소 제한, 좌석 합계, 대리 수정 권한/감사 기록, 잠금 만료/검색 와일드카드, 수동 규칙 TTL/허용 해제, 알림 중복 이벤트/재시도/오래된 lease 배제.

- 전체 gateway에서 V016/V017 마이그레이션 및 refund backfill SQL 실행 통과.
- 변경 diff gitleaks 검사: **no leaks found**.

## 발견·수정

- 새 삭제 버튼에 ‘준비 중’ 문구가 포함되어 기존 E2E 선택자가 둘을 가리켰다. 상태 배지는 정확한 문구로 선택하도록 수정.
- 관리자 대리 수정 테스트는 DB 역할 부여만으로 기존 JWT가 관리자 권한을 갖는다고 가정했다. 실제 인증 규칙에 맞게 재로그인한 토큰으로 검증.
- API 클라이언트의 `json` 옵션 계약과 맞지 않던 새 관리 폼을 TypeScript 검사에서 발견해 수정.
- 수동 매진 회차도 시작 시각이 지나면 자동 종료되도록 보강.
- 판매 오픈·할인·좌석 배치 변경의 잠금 및 최신 엔티티 재조회 보강.

## 완료로 처리하지 않는 것

실제 PG, 실제 휴대폰 푸시/실기기 Safari, 관리자 암호가 필요한 호스트 방화벽, 복구 키의 사용자 소유 외부 보관, 다중 리전 HA/초대규모 부하 검증은 별도 환경 작업이다. 부분 환불·양도·QR 검표는 이번 요청의 구현 범위에 포함하지 않았다. 판매 중 특정 좌석을 일시 제외하는 기능 대신 판매 전 행 삭제를 제공한다. 알림은 at-least-once이며 제공자 수신 직후 장애 시 중복 가능성이 있다.
